# Texcavator brand files

Print-ready vector files, for merch and anything outside the website.

| File                         | Use                                                                         |
| ---------------------------- | --------------------------------------------------------------------------- |
| `texcavator-logo-light.svg`  | Primary lockup: logo mark, wordmark and tagline, for light backgrounds      |
| `texcavator-logo-dark.svg`   | Primary lockup for dark backgrounds and dark garments                       |
| `texcavator-mark-light.svg`  | Logo mark on its own (avatars, favicons, pins, embroidery)                  |
| `texcavator-mark-dark.svg`   | Logo mark, night version                                                    |
| `texcavator-mark-mono.svg`   | Logo mark in one colour (stamps, single-colour screen printing, embroidery) |
| `texcavator-badge-light.svg` | The illustrated badge (stickers, t-shirts, large prints), by day            |
| `texcavator-badge-dark.svg`  | The illustrated badge, by night                                             |

The **mark** is the logo: simple enough to work at 16 px and in one colour. The **badge** is the brand illustration: use it large, never as a favicon or avatar.

All lettering is converted to outlines (Space Grotesk Bold and IBM Plex Mono, shaped with HarfBuzz), so the files need no fonts installed. Colours are sRGB hex from the logo palette:

Sand `#F3E9D7` · Ochre `#D9A566` · Rust `#B97A3E` · Umber `#8A5528` · Brass `#E8B04A` · Phosphor `#7FD67A` · Charcoal `#2B2B2B` · Night `#26323D`

The badge also uses `#E6DCC6` (terminal case), `#1E2A22` (screen) and `#C9CED6` (trowel blade).
